```md id="u5m2ka"
# AI RULES

# Affterun

Turning runs into indie posters.

---

# 1. Core Philosophy

Affterun adalah project kecil dengan fokus kuat pada:
- visual
- feeling
- shareability
- simplicity

Project tidak boleh berkembang menjadi aplikasi fitness kompleks.

---

# 2. Main Product Direction

Affterun bukan:
- fitness tracker
- running analytics platform
- social media app
- AI application

Affterun adalah:
- poster generator
- visual remix tool
- indie social sharing experience

---

# 3. Mandatory Rules

## 3.1 Mobile First

Semua UI wajib:
- responsive
- mobile-first
- portrait oriented
- nyaman dipakai satu tangan

Target utama:
Instagram Story workflow.

---

## 3.2 Keep It Lightweight

Project harus tetap:
- kecil
- cepat
- sederhana

Hindari:
- enterprise architecture
- backend kompleks
- unnecessary abstraction
- over engineering

---

## 3.3 No AI APIs

Dilarang menggunakan:
- OpenAI API
- Gemini API
- Claude API
- image generation API
- LLM service

Semua output harus dibuat menggunakan:
- template system
- preset system
- deterministic rendering
- HTML/CSS composition

---

# 4. Poster Rendering Rules

## 4.1 HTML/CSS Based

Poster wajib dibuat menggunakan:
- HTML
- CSS
- Tailwind
- image overlays

Bukan AI generated image.

---

## 4.2 Canvas Usage

Canvas hanya digunakan untuk:
- export PNG
- image capture

Bukan untuk full rendering engine.

---

## 4.3 Style Consistency

Setiap style harus memiliki:
- identitas visual jelas
- typography konsisten
- filter konsisten
- layout konsisten

---

# 5. Visual Identity Rules

## Overall Mood
Visual harus terasa:
- cinematic
- indie
- emotional
- modern
- editorial

---

## Avoid
Jangan membuat visual:
- terlalu sporty
- terlalu gaming
- terlalu corporate
- terlalu dashboard-like
- terlalu colorful random

---

## Preferred References
Visual direction:
- indie movie poster
- japanese editorial
- analog film
- travel zine
- magazine typography
- urban photography

---

# 6. User Experience Rules

## Main UX Goal
User harus bisa:
Paste Link → Upload Photo → Choose Style → Generate → Download

Dengan cepat dan minim friction.

---

## Avoid
Jangan menambahkan:
- onboarding panjang
- banyak step
- settings rumit
- hidden menu
- unnecessary options

---

# 7. Technical Rules

## State Management
Gunakan:
- React useState
- simple props

Tidak perlu:
- Redux
- Zustand
- MobX

---

## Backend Rules
Untuk MVP:
- backend optional
- database tidak wajib
- authentication tidak perlu

---

## Deployment Rules
Target deployment:
- Vercel
- static hosting
- low-cost deployment

---

# 8. Performance Rules

Target:
- fast loading
- smooth scrolling
- lightweight rendering

Avoid:
- large libraries
- heavy animation
- unnecessary effects

---

# 9. Export Rules

Output wajib:
- portrait format
- 1080x1920
- Instagram Story ready

Export harus:
- cepat
- stabil
- tidak blur

---

# 10. Typography Rules

Typography adalah elemen utama.

Gunakan:
- bold editorial typography
- whitespace
- cinematic hierarchy

Avoid:
- terlalu banyak font
- font decorative berlebihan
- typography kecil sulit dibaca

---

# 11. Style Preset Rules

MVP hanya memiliki 6 style:

1. AFTER SUN
2. TRAVEL ZINE
3. PATIENCE
4. RETRO POSTER
5. MINIMAL GRID
6. FILM FRAME

Jangan menambahkan style baru sebelum:
- semua style stabil
- visual konsisten
- export berjalan baik

---

# 12. Scope Protection

Jika ada ide fitur baru:
selalu evaluasi:

"Apakah ini membuat Affterun lebih fokus atau malah berubah menjadi aplikasi fitness biasa?"

Jika jawabannya:
- menambah kompleksitas
- mengubah arah visual
- membuat flow lebih panjang

Maka fitur harus ditolak.

---

# 13. Branding Rules

Affterun harus terasa seperti:
- small internet project
- indie visual tool
- niche creative product

Bukan:
- startup fitness corporate
- enterprise SaaS
- AI wrapper product
```
